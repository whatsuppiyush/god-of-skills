# Superpowers Brainstorming

Starts from the observation that an agent builds what it believes you want, and that belief is thinner than it feels. Before replying, the model asks what it truly knows. If everything that matters is in the request it simply does the task, and if something non-trivial is missing it opens a conversation. The skill then plays the understanding back, sizes the work, and writes up a design. It is explicitly not limited to software, and applies to a talk, a business or a renovation. A red-flags list catches the moments when the model is about to guess instead of asking.

## Use it to

- Pin down the real requirements for a vague feature request before writing any code
- Turn a half-formed product idea into a written design you can review
- Decide whether a request is a quick task or deserves a longer conversation
- Plan a non-software project such as a conference talk with the same questioning discipline
