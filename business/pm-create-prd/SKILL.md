# PM Skills: Create PRD

Produces a PRD sized for a decision. The eight sections are summary, contacts, background, objective, market segments, value propositions using a six-part jobs-to-be-done template, solution and release. Lean is the default, about one to two pages, with a fuller spec available on request, because the document's purpose is to align engineers, designers, leadership and stakeholders on what to build and why. It can also review an existing PRD. The model plays an experienced product manager and gets the product or feature description as its input. Notes and further reading point to the deeper concepts.

## Use it to

- Write a one-page PRD for a new feature from a short description
- Review an existing PRD for gaps in objective and release criteria
- Express value propositions as jobs to be done
- Produce a fuller spec for engineering from the same lean draft
