# Diagram Design

Produces diagrams as single HTML files with inline SVG, using an editorial design system and forty-five visual types. It separates semantic patterns, which describe behavior, from type references, which describe layout, and covers architecture, flowcharts, sequence, state machines, ER, timelines, swimlanes, quadrants, radar, Venn, pyramid, treemap, heatmap, waterfall and many chart variants. A first-time setup gate checks whether the style guide still holds shipped defaults and pauses to ask. It includes anti-patterns, mandatory connector rules, a complexity budget per diagram and a summary card pattern.

## Use it to

- Draw an architecture diagram in your brand colors as a single HTML file
- Pick the right diagram type for a process or data model
- Create a swimlane or sequence diagram that follows consistent connector rules
- Stay within a complexity budget so diagrams remain readable
- Check an existing diagram against the skill's anti-patterns before presenting it to leadership
