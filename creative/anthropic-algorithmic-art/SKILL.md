# Anthropic Algorithmic Art

Generative art in two stages. The model first writes an algorithmic philosophy, a short manifesto about the computational process it wants to express, then implements it in p5.js with seeded randomness so the same seed always reproduces the same piece. Output is a markdown philosophy, a JavaScript algorithm file and an HTML viewer with parameter controls for exploring variations. The instructions require reading the bundled template before writing code and set expectations for craftsmanship. Typical subjects are noise fields, flow fields, particle systems and emergent patterns rather than static illustrations.

## Use it to

- Create a reproducible generative cover image where a seed number selects each variant
- Build an interactive page with sliders for exploring a flow-field algorithm
- Prototype a particle system aesthetic for a landing-page background
- Generate a limited series of seeded artworks and record which seed produced which
