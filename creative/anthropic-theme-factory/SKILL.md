# Anthropic Theme Factory

A theming toolkit rather than a design generator. It ships ten curated themes, each pairing a palette with header and body fonts, and a showcase PDF so you can see them before choosing. The workflow is deliberately slow and explicit: show the showcase, ask which theme, wait for confirmation, then apply the chosen colors and fonts consistently to the artifact. It works on slide decks, documents, reports and HTML landing pages. If none of the presets fit, it can generate a custom theme on the fly and apply it the same way.

## Use it to

- Restyle a finished slide deck in a different preset without rewriting content
- Give a set of internal documents one consistent color and font treatment
- Pick between several themes by viewing them side by side first
- Create a custom theme for a client and apply it across a report and a landing page
