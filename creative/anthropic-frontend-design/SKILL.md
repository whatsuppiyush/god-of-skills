# Anthropic Frontend Design

Frames the model as a studio design lead whose client has already rejected templated work. It starts by grounding the design in the actual subject and audience, then asks for a compact token plan: four to six named hex colors, typefaces and their roles, a layout concept with ASCII wireframes, and guiding principles. That plan is reviewed against the brief before any code is written. The skill also names the habits that mark a page as generated, from cream backgrounds with terracotta accents to identical rounded cards and tracked all-caps eyebrow labels, and ends with a self-critique pass.

## Use it to

- Design a landing page for a niche product that does not resemble every other SaaS site
- Review an existing interface against a stated brief and list which choices are defaults rather than decisions
- Produce a color, type and layout token plan for stakeholders to approve before implementation
- Replace stock hero sections with one built from the most characteristic thing in the subject's world
