# Taste Skill

Art direction for websites, based on a study of 247 curated gallery sites. A script deals three of twenty researched directions and you choose the one that carries the subject's idea; the script then supplies its type system, palette, photographs and section blueprints. A run of ten steps covers reading the brief, writing the argument, drawing a direction, finding the idea, writing the words, building, gating with a real-browser inspector, looking at screenshots and fixing, and adding motion. House rules and laws of the craft forbid the default centered headline over icon cards. Special cases and files are documented.

## Use it to

- Pick a distinctive art direction for a new marketing site
- Run the inspector over a built page and fix what it flags
- Write copy and section blueprints that follow a chosen direction
- Use the look-and-fix loop to refine a page from screenshots

## How to use it

**Claude Code**
1. Inside Claude Code, add the marketplace and install the plugin.
2. /plugin marketplace add Leonxlnx/taste-skill
3. /plugin install taste-skill@taste-skill
4. Or install only this skill with the skills CLI.
5. $ npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
