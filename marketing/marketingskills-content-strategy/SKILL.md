# Marketing Skills: Content Strategy

Helps answer the question of what to write about. It gathers business context, customer research, the current content state and the competitive landscape, then applies a framework that treats content like a product. A central distinction is searchable content, which earns traffic through demand that already exists, versus shareable content, which earns attention through ideas people pass on. Each has its own writing rules. The skill also lists content types and plans pillars, clusters and an editorial calendar. It is a planning tool, not a drafting one.

## Use it to

- Choose content pillars and a first set of topics for a new blog
- Decide which planned pieces should be searchable and which shareable
- Build a topic cluster around a product category
- Turn a vague content roadmap into a prioritised editorial calendar
- Audit an existing blog for gaps between searchable and shareable pieces, then plan the next quarter's slots
