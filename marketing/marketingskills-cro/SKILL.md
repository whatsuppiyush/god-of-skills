# Marketing Skills: Conversion Rate Optimization

Reads a marketing page or form and diagnoses it along seven axes: value proposition clarity, headline effectiveness, call-to-action placement and hierarchy, visual hierarchy and scannability, trust signals, objection handling and friction points. Findings come back in a set format, starting with quick wins you can implement now, then higher-impact changes, then things to test. Reference files for specific page types are loaded when the page matches, so a signup form gets different advice than a pricing page. It is compact, around a thousand words, and meant to be run page by page.

## Use it to

- Get a prioritised list of fixes for a landing page that is not converting
- Review a lead form for fields and friction that cost submissions
- Check a pricing page for unanswered objections above the fold
- Produce a list of A/B test hypotheses ranked by likely impact
