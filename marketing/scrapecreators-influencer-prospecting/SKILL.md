# ScrapeCreators Influencer Prospecting

Builds prospect lists of creators, influencers or affiliates in a niche for outreach, partnerships, sponsorships, UGC or seeding. It looks for accounts that fit the niche, have enough reach and show evidence of relevant content or audience fit, scores them with a defined framework, and outputs a table with best fits, outreach angles and a CSV. A short list of common pitfalls is included. Data comes from the ScrapeCreators API, which requires a key, and the skill is about three hundred and forty words, so it loads cheaply alongside the other research skills.

## Use it to

- Compile a scored list of creators for a seeding campaign
- Pick outreach angles tailored to each prospect's content
- Export a CSV of prospects to a sequencing tool
- Find affiliates in a niche with demonstrable audience fit
- Review the fit scores with a partner manager and remove prospects who clash with the brand

## How to use it

**Claude Code**
1. Install with the skills CLI.
2. $ npx skills add ScrapeCreators/social-media-research-skills
3. The skill calls the ScrapeCreators API, so set your key.
4. $ export SCRAPECREATORS_API_KEY=your_key
