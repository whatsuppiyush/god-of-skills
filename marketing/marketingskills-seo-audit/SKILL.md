# Marketing Skills: SEO Audit

Run it when traffic dropped, pages are not ranking or you want a health check. The audit follows a priority order and covers crawlability, indexation, site speed and Core Web Vitals, mobile friendliness, security and HTTPS, and URL structure, then on-page work. A separate section handles international SEO, including hreflang, canonicalization for multilingual sites, international sitemaps and locale issues. It also flags a schema-detection limitation to keep in mind when reporting missing markup. Output is a set of actionable recommendations rather than a raw issue dump.

## Use it to

- Diagnose why organic traffic fell after a site change or algorithm update
- Check crawl and indexation problems on a new site
- Audit hreflang and canonical tags on a multilingual site
- Produce a prioritised fix list for a developer to work through
- Turn the audit output into a ticket list a developer can estimate in one sitting
