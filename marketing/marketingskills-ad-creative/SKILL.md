# Marketing Skills: Ad Creative

Works in four modes: generate from scratch, iterate from performance data, produce scaled static batches grounded in real inputs, and run a creative strategy loop. Before writing it collects platform and format, product and offer, audience and intent, any performance data, and constraints. Platform specs for Google responsive search ads, Meta, LinkedIn, TikTok and X are built in, so each variation is validated against limits and organised for upload. Generation starts by defining angles, then produces variations per angle. When data exists, it analyses winners and losers before proposing new variants, rather than starting over.

## Use it to

- Write a bulk set of Google responsive search ad headlines organised by angle
- Turn last month's top and bottom performing ads into a fresh batch of variants
- Produce Meta and LinkedIn copy variations that already fit each platform's limits
- Plan a creative testing loop with angles tied to the product and offer
