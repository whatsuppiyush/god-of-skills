# Marketing Skills: Onboarding CRO

Focused on what happens after signup. The core principles are that time to value is everything, each session should have one goal, doing beats showing, and visible progress motivates. It draws on onboarding psychology and a ten-component toolkit, and helps you define activation by finding the aha moment and choosing activation metrics. Flow design guidance covers the first thirty seconds after signup. It applies when users are not activating, nobody finishes setup, or the first-run experience is weak, and it works from empty states and checklists to onboarding emails.

## Use it to

- Define what counts as an activated user and how to measure it
- Redesign the first-run screen so a new user reaches value in one session
- Write an onboarding checklist that shows progress
- Audit empty states for dead ends
- Review an email onboarding series alongside the in-product flow so the two stop repeating each other
