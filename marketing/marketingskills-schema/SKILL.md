# Marketing Skills: Schema Markup

A focused guide to structured data. It sets four principles: accuracy first, use JSON-LD, follow Google's guidelines and validate everything. It then lists common schema types with quick-reference snippets for Organization, Article, Product, FAQPage and BreadcrumbList. A step to check which features Google still supports comes before choosing a type, since not every type earns a rich result. It explains combining multiple types on one page and ends with validation and testing. Use it for FAQ, product, review and breadcrumb markup, star ratings in search and knowledge panel signals.

## Use it to

- Add Organization and Article markup to a content site
- Mark up a product page with price, availability and reviews
- Check whether a schema type is still eligible for Google rich results
- Validate existing JSON-LD and fix errors in the output
- Generate FAQ markup for a help center page and confirm it matches the visible questions
