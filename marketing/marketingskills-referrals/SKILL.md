# Marketing Skills: Referral and Affiliate Programs

Starts by asking whether to engineer virality first, then distinguishes customer referral programs from affiliate programs. Program design follows the referral loop: identify trigger moments, design the share mechanism and choose the incentive structure. A section on optimization covers improving referral rate, A/B tests to run and common problems with fixes. Measurement defines key metrics and typical findings. It closes with a launch checklist for before launch, launch and the first thirty days, plus email sequences for the program launch and a nurture track. Partner programs and word-of-mouth are in scope.

## Use it to

- Design a refer-a-friend loop around the moment customers feel the most value
- Decide between a customer referral program and an affiliate program
- Write the launch and nurture emails for a referral program
- Set the metrics and A/B tests for improving referral rate
