# Marketing Skills: Programmatic SEO

Guidance for creating many search pages from templates and data without falling into thin content. Principles come first: unique value per page, proprietary data winning, clean URL structure, a genuine match to search intent, quality over quantity and avoiding Google penalties. It presents twelve playbooks, including location, comparison and integration pages, and a method for choosing one. The implementation framework runs through keyword pattern research, data requirements and template design. It applies to directory pages, keyword plus city pages and any plan that generates hundreds of URLs, and keeps asking whether each page deserves to exist.

## Use it to

- Choose the programmatic playbook that fits your data and keywords
- Design a template where each generated page carries unique data
- Define a keyword pattern and check it for real search demand
- Review a planned set of pages against the thin-content risks
