# LinkedIn Skills: Profile Optimizer

Scores a profile on nine components: photo, banner, headline, About, Featured, Experience, Skills, custom URL and recommendations. It then rewrites each section that needs it, converting a resume-style profile into one aimed at inbound interest. A seven-step approach to the About section is part of it, benchmarks are cited from named research, and hard rules and reference files are included. The user pastes their profile text, since the skill can't read a bare URL. Typical requests are to review a profile, rewrite a headline, fix an About section or optimize a banner.

## Use it to

- Score a profile on a nine-part scorecard before changing anything
- Rewrite a headline and About section for inbound leads
- Add outcome metrics to Experience entries
- Plan which items to feature and which recommendations to request
- Rewrite the Featured section so it points at the three assets most likely to start conversations
