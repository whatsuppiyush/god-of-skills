# ScrapeCreators Outlier Post Finder

The goal isn't sorting by views. The skill pulls recent public posts, normalizes engagement metrics, calculates each account's baseline and surfaces the posts that performed unusually well for that creator or brand. The report lists the biggest outliers, repeatable patterns, hooks to steal and content ideas, with source URLs, caveats and common pitfalls. It supports posts, reels, shorts and tweets, and uses the ScrapeCreators API, which needs a key. The result is a swipe file grounded in relative performance, so a small account's breakout is not buried by a large account's averages.

## Use it to

- Find a competitor's best-performing posts relative to their usual numbers
- Extract hooks and formats from the outliers
- Build a content idea list from patterns that repeat
- Compare outliers across several creators in a niche
- Check whether an outlier depended on a one-off event before copying its format

## How to use it

**Claude Code**
1. Install with the skills CLI.
2. $ npx skills add ScrapeCreators/social-media-research-skills
3. The skill calls the ScrapeCreators API, so set your key.
4. $ export SCRAPECREATORS_API_KEY=your_key
