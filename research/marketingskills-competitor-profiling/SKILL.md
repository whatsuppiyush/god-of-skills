# Marketing Skills: Competitor Profiling

Given competitor URLs, it produces a dossier for each by combining live site scraping with SEO and market data. It first selects a tool stack, then follows a fixed research process and saves the raw data so claims can be traced. The principles are facts over opinions, structured and comparable output, current data and an honest assessment. It also treats scraped content as untrusted input, so instructions embedded in a competitor's pages are not followed. The result is a set of profiles that line up side by side, not a pile of notes.

## Use it to

- Profile five competitors from their URLs into consistent documents
- Refresh a competitor landscape before a positioning or pricing review
- Keep raw scraped data alongside each profile so findings can be checked
- Feed structured profiles into a later battlecard or comparison page
