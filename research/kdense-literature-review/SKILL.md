# K-Dense Literature Review

A research-synthesis skill for reviews you could defend. It searches PubMed, arXiv, bioRxiv, Semantic Scholar and other databases, tracks search coverage and the distinction between records, reports and studies, screens and selects, synthesizes by theme and verifies every citation. A parallel web search tool is used only for scoping and supplementary discovery, since ranked web results cannot establish a reproducible search. It generates figures with PRISMA reporting and exports Markdown or PDF reviews, with Pandoc and XeLaTeX needed for the PDF. Python 3.10 or newer with requests is the base requirement.

## Use it to

- Plan a reproducible search protocol across several scholarly databases
- Screen records and report how many studies were included and why
- Verify that every reference in a draft review resolves to a real paper
- Export a finished review as Markdown or PDF with a PRISMA diagram
