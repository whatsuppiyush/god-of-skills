# ScrapeCreators Ad Library Teardown

Studies public ad library data to show how a competitor sells. It collects active ads from the Meta, Google or LinkedIn libraries, then reports messaging angles, a hooks-and-headlines swipe file, offers and calls to action, video transcript notes, what the advertiser appears to be testing and recommended tests for you. Landing page claims can be compared against the ad copy. It relies on the ScrapeCreators API for data and needs a key. The output is meant to be practical for marketers writing ads or deciding which angles to test.

## Use it to

- Tear down a competitor's active Meta ads into angles and hooks
- Compare offers and CTAs across a market's advertisers
- Transcribe competitor video ads and note their structure
- Turn observed ad patterns into a list of tests
- Track a competitor's ads month over month to see which angles they keep running

## How to use it

**Claude Code**
1. Install with the skills CLI.
2. $ npx skills add ScrapeCreators/social-media-research-skills
3. The skill calls the ScrapeCreators API, so set your key.
4. $ export SCRAPECREATORS_API_KEY=your_key
