# Knowledge Work: Competitive Intelligence

Mode A is an on-demand play for a specific deal against a named competitor. Mode B looks across your book of business for win and loss patterns and competitor mentions, and produces battlecards and a weekly digest. Both pull evidence first and then analyse it. The skill answers questions such as how you compare to a competitor, what is new with them, or what a battlecard should say. It sits inside Anthropic's sales plugin and follows the same grounding rules about live CRM schemas and citations, so findings point back to records rather than relying on memory.

## Use it to

- Get a play for a live deal where a specific competitor is in the running
- Review win/loss patterns across closed opportunities
- Generate a weekly digest of competitor mentions
- Build battlecards backed by deal evidence
- Feed the win and loss patterns into next quarter's sales training

## How to use it

**Claude Code**
1. In a terminal, add the marketplace and install the plugin that holds this skill.
2. $ claude plugin marketplace add anthropics/knowledge-work-plugins
3. $ claude plugin install sales@knowledge-work-plugins
