# Knowledge Work: Account Research

Researches a target company and, if you name one, a specific contact. It checks the CRM first so existing records and relationships are not missed, then researches the company's overview, recent news and likely priorities, scores fit against your ideal customer profile and proposes relevance hooks for outreach. The output cites what it read. Like other plugin skills, it follows rules about grounding on the live CRM schema and distinguishing blank fields from fields it did not query. Use it for prospect research, looking up a person or gathering intel before reaching out.

## Use it to

- Research a target account before the first outreach
- Score a company against your ICP with stated reasoning
- Find recent news that gives a relevant opening line
- Check what the CRM already knows about a person before contacting them
- Save the relevance hooks to the CRM so the next rep does not repeat the research

## How to use it

**Claude Code**
1. In a terminal, add the marketplace and install the plugin that holds this skill.
2. $ claude plugin marketplace add anthropics/knowledge-work-plugins
3. $ claude plugin install sales@knowledge-work-plugins
