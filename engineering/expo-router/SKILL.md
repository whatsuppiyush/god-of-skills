# Expo Router Navigation

Navigation guidance for Expo Router, maintained by the Expo team. It covers file-based routes, route groups, dynamic routes and folder organization, then the Link component with previews and context menus, the native Stack, page titles, modals and form sheets, NativeTabs, headers, toolbars and header search bars. Code style and library preferences keep generated code consistent. Styling, controls and visual effects are handed off to a separate native UI skill, and motion to an animation skill, so this one stays on routing. Use it when adding screens or reworking navigation in an Expo project.

## Use it to

- Set up route groups and dynamic routes for a new Expo app
- Add a native tab bar and a modal screen to existing navigation
- Show link previews and context menus on press
- Fix page titles and header search bars in a stack

## How to use it

**Claude Code**
1. Inside Claude Code, install the Expo plugin from the official marketplace.
2. /plugin install expo@claude-plugins-official
3. Or use the skills CLI.
4. $ npx skills@latest add expo/skills --skill expo-router
