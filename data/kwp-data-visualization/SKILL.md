# Knowledge Work: Data Visualization

Chart selection by data relationship, plus Python code patterns. It shows what to use for comparison, distribution, relationship and trend, when not to use certain charts, and ready patterns for line charts, bar charts, histograms, heatmaps and small multiples, with number formatting helpers and interactive Plotly examples. Design principles include accessibility and color theory. It is for building charts, publication-quality figures and choosing a chart type for a dataset. It belongs to Anthropic's data plugin, alongside the statistical-analysis and SQL skills, and pairs with them when analysis moves from numbers to a picture.

## Use it to

- Choose between a bar chart and a line chart for a given comparison
- Produce a publication-quality figure with matplotlib
- Build an interactive plot with plotly for a dashboard
- Make a chart readable for colour-blind viewers
- Review an existing dashboard for charts where a different type would make the comparison easier
