# Knowledge Work: Performance Report

Builds a marketing performance report from the data you supply. Sections are an executive summary, a key-metrics dashboard, trend analysis, what worked, what needs improvement, insights, recommendations and a focus for the next period, followed by metric definitions and benchmarks. It is for wrapping up a campaign or for weekly, monthly or quarterly channel summaries aimed at stakeholders, translating raw numbers into a narrative with priorities. It is the longest of the marketing plugin skills at nearly three thousand words and is triggered by /performance-report or requests for campaign results.

## Use it to

- Write a monthly channel report with trends and recommendations
- Wrap up a campaign with what worked and what did not
- Summarise metrics for executives in one page
- Set next-period priorities based on the data
- Draft the executive summary first, then fill the detailed sections only where leadership asks

## How to use it

**Claude Code**
1. In a terminal, add the marketplace and install the plugin that holds this skill.
2. $ claude plugin marketplace add anthropics/knowledge-work-plugins
3. $ claude plugin install marketing@knowledge-work-plugins
