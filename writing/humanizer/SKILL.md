# Humanizer

Rewrites AI-sounding text so it reads like the writer and not a chatbot, without changing what it says or inventing anything. The explanation is that a model picks the choice that fits the widest range of readers, whereas a human picks for one reader and one subject. Patterns are grouped by cause: staging instead of stating (not X but Y, one-line closers, sayings that sound deep), rhythm by rule (forced triads, repeated openings, dashes as the universal connector, stacked qualifiers), inflation, and formatting by rule. It asks for a matched voice and a clear return format. It is a long, detailed skill.

## Use it to

- Edit a draft so it stops using not-X-but-Y constructions and forced triads
- Strip inflated phrasing from a press release without changing facts
- Match a rewrite to your own voice sample
- Run a quick audit of a blog post for formatting-by-rule habits

## How to use it

**Claude Code**
1. Inside Claude Code, add the marketplace and install the plugin.
2. /plugin marketplace add blader/humanizer
3. /plugin install humanizer@humanizer
4. Invoke it with /humanizer:humanizer.
